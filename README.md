# minni
browser based minecraft engine very simple and basic, feel free to modify

!IMPORTANT! = this shit is stupid so idk how i did stuff but i do have some stuff in the code marked like render distance is defined in renderDistance (CTRL+F to search)
if you set the render distance higher than 3 you will notice that it takes more time to load
placed blocks are also very buggy as they may:
    - break your hitbox
    - make you teleport (use wallhacks)
    - not collide
    - make you fly
thats why i recommend placing the blocks slow
also the textures wont load since you dont have them but just head over to the default-textures branch and youll find them then put those textures into the same directory as index.html
if you have any bug reports well sorry but i dont do bug patches
sorry for no anti-aliasing shader (they cost performance)
